# Template — Post X (fintwit IT)

> Voce: `_contesto/guida-voce-brand.md`. Minuscole, sobrio, zero hype.
> Prima riga = gancio (verdetto o dato), mai preamboli.

## Post singolo

```
[gancio: il dato o il verdetto, secco]

[2-3 righe: il meccanismo, coi numeri e la fonte]

[cosa lo invaliderebbe, 1 riga]

[link pagina tesi o grafo]
[screenshot]
```

## Thread (3-5 tweet, per le tesi raccontate)

```
1/ [la tesi in corsivo virgolettata + conf%]
   [screenshot pagina tesi]

2/ il ragionamento: [meccanismo + dati con fonte]

3/ i segnali: cosa la conferma ✓ / cosa la invalida ✗
   [qui la differenza col guru: la smentita è dichiarata prima]

4/ [punto di metodo — la lezione generalizzabile]

5/ tesi completa, coi segnali che si aggiornano sui dati:
   [link /market/t/[id]?utm_source=x&utm_medium=organic]
   contenuto educativo, non consulenza finanziaria
```

## Build in public

```
[numero o evento onesto: "20 tesi pubbliche sul marketplace, 4 autori"]

[cosa ho imparato / deciso / rotto e riparato — 2-4 righe]

[cosa viene dopo, 1 riga]
```

## Regole rapide

- 1 idea per post; se servono due idee, sono due post
- niente emoji-pioggia (max 1, dai glifi del brand: ● ◆ ▤ ⑂ ✓ ✗)
- niente hashtag ammucchiati (0-1)
- link con UTM: `?utm_source=x&utm_medium=organic`
- se si parla di strumenti → disclaimer breve in coda
